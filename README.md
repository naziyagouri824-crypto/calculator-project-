# 🧮 Simple Calculator

A beginner-friendly calculator web application built while learning HTML, CSS, and JavaScript.

## ✨ Features

* Basic arithmetic operations: addition, subtraction, multiplication, and division
* Percentage calculation
* Clear (`C`) button
* Delete (`DEL`) button
* Decimal number support
* Responsive and clean calculator interface
* Interactive buttons with hover and click effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
calculator-project-/
├── index.html
├── style.css
├── script.js
└── README.md
```

Through this project, I practiced:

* Performing calculations using JavaScript
